# 📊 Excel Sales Dashboard

## 📌 Project Overview

This project is an **interactive Sales Analytics Dashboard created using Microsoft Excel**. The dashboard is designed to analyze sales performance, revenue trends, customer activity, product performance, occasions, locations, and delivery time.

The project uses raw sales, customer, and product data and transforms it into meaningful business insights using **Excel Tables, Pivot Tables, Pivot Charts, KPIs, formulas, slicers, and data analysis techniques**.

---

## 🎯 Project Objective

The main objective of this project is to convert raw sales data into an easy-to-understand dashboard that can help identify:

* Overall revenue performance
* Order volume and customer activity
* Monthly sales trends
* Product-wise revenue
* Category-wise performance
* Occasion-wise revenue
* Location-wise order distribution
* Order quantity and delivery-time relationship
* Average revenue and delivery performance

## 📂 Dataset Structure

The workbook contains multiple sheets used for analysis:

| Sheet         | Description                                                                            |
| ------------- | -------------------------------------------------------------------------------------- |
| **KPI**       | Contains key performance indicators and summarized analysis                            |
| **Dashboard** | Main interactive dashboard                                                             |
| **Customer**  | Customer information such as ID, name, city, gender and contact details                |
| **Order**     | Order-level information including quantity, dates, delivery time, location and revenue |

## 📈 Key KPIs

The dashboard focuses on important business metrics such as:

* 💰 **Total Revenue**
* 📦 **Total Orders**
* ⏱️ **Average Delivery Time**
* 💵 **Average Revenue per Order**
* 📊 **Order Quantity vs Delivery Time Correlation**

These KPIs provide a quick overview of the overall business performance.

---

## 📊 Dashboard Analysis

### 1. Monthly Revenue Analysis

Analyzes revenue generated across different months to identify high-performing and low-performing periods.

### 2. Product Performance

Compares revenue generated by different products to understand which products contribute the most to overall sales.

### 3. Category Analysis

Shows revenue distribution across product categories such as:

* Cakes
* Colors
* Mugs
* Plants
* Raksha Bandhan products
* Soft Toys
* Sweets

### 4. Occasion Analysis

Analyzes revenue based on different occasions, including:

* Anniversary
* Birthday
* Diwali
* Holi
* Raksha Bandhan
* Valentine's Day
* Other occasions

### 5. Location Analysis

Provides an overview of order distribution across different cities/locations.

### 6. Delivery Time Analysis

Analyzes the difference between order and delivery dates/times to understand delivery performance.

### 7. Correlation Analysis

The dashboard also examines the relationship between **Order Quantity and Delivery Time** using correlation analysis.

## 🔍 Key Insights

Some of the important observations from the analysis include:

* The business generated approximately **₹35.21 lakh in total revenue**.
* The dataset contains **1,000 order records**.
* **Colors** generated the highest revenue among the analyzed product categories.
* **Soft Toys and Sweets** also contributed significantly to overall revenue.
* Revenue varies considerably across months, helping identify stronger and weaker sales periods.
* Occasion-based analysis helps identify customer purchasing patterns.
* Delivery-time analysis can help identify opportunities for improving operational efficiency.

> **Note:** The insights above are based on the current dataset and dashboard calculations.
